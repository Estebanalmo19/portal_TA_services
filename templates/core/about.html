Acerca de este portal

Qué es esto

{{ BRAND_NAME }} es un MVP de demostración que centraliza siete soluciones ficticias de Talent Acquisition, HR Colombia, Security, Data & Analytics y Operations, más un asistente local (Agent TA). Todos los datos son sintéticos: nombres, correos @example.com, incidentes, tickets y métricas.

El selector de perfil no es autenticación real

Al entrar eliges un perfil (Manager, Solution Owner o Analyst) que solo se guarda en sessionStorage de esta pestaña. No hay usuarios, contraseñas ni permisos reales: es una simulación de qué recorrido vería cada rol, no un control de acceso ni una frontera de seguridad.

Cómo se guarda el estado

Django no usa base de datos: sirve un snapshot inicial de datos de ejemplo y valida cada operación (crear, asignar, comentar, cambiar estado) con servicios en Python. El navegador guarda ese estado — y tus cambios — en sessionStorage mientras dura la pestaña; localStorage solo guarda preferencias visuales (tema, sidebar). «Restablecer demo», en el menú de perfil, borra los datos de esta pestaña y vuelve a cargar el estado inicial.

Límites de esta demo

  • Sin autenticación, autorización o base de datos reales.
  • Sin integraciones externas: correo, HiBob, Microsoft 365, Power Automate o cualquier API de negocio.
  • Agent TA es un motor de reglas local (FAQ + coincidencia de intención); no es un modelo de lenguaje ni se conecta a uno.
  • Los SLA, políticas y guías marcadas como «Guía de demostración» son ficticios y existen solo para dar contexto a esta demo.
  • No es apto para producción tal cual: falta hardening de seguridad, persistencia real y gobierno de datos.

Evolución hacia producción (no implementado en este MVP)

  • Persistencia: migrar de mocks en memoria a PostgreSQL con migraciones de Django, auditoría y respaldo.
  • Identidad: autenticación empresarial real (SSO / Microsoft 365) en lugar del selector de perfil.
  • Integraciones: Microsoft 365 (correo/calendario), Power Automate (flujos), HiBob (datos de HR) y otras APIs internas de negocio.
  • Operación: observabilidad, control de acceso por rol real, y políticas de retención de datos.
